## AI Models & API Integration
1. **Soil Classification API (Model 1):** Built with `ResNet50` deep learning architecture to classify soil types from field photos, determine agricultural suitability, and recommend suited crops.
2. **Chemical Nutrient Analysis API (Model 2):** Trained using `Random Forest` (achieving 88.81% accuracy) on soil chemical parameters (N, P, K, pH) to accurately predict optimal crop matching.
